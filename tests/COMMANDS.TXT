Playwright Commands:
     To run files: 
        1. npx playwright test --> runs all the playwright tests
        2. npx playwright test filename --> runs that specific test(filename)
        3. npx playwright test --g "description" --> runs test by name
        4. npx playwright test --headed --> runs test in headed mode
        5. npx playwright test --ui --> runs tests in UI mode
        6. npx playwright test --project=browser name --> runs tests in that specific browser
        7. npx playwright show-report --> generate and view test report
        8. npx playwright test hooks2.spec.ts --headed --reporter=html

Integrating Allure Report:
   Steps:
      1. npm install -D allure-playwright -- install this commandline
      2. Add this info at config file : 
      reporter: [
  ['list'],
  ['allure-playwright', { outputFolder: 'allure-results' }]
],
      3.allure generate allure-results --clean 
      4. allure open
